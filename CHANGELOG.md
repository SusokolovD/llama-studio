# Версия 0.3.0

- Вкладка обновления и сборки llama.cpp: исходники, редактируемые команды, папка бинарников и отдельная папка llama-build.
- Последовательное выполнение git pull --ff-only и команд, журнал и отмена.
- Установка готовых файлов с заменой, подготовкой копий и откатом при ошибке; автоматический выбор готовой папки для сервера.
- Настройки сборки сохраняются в JSON.
- Версия в шапке, заголовке окна и свойствах Windows exe; встроенная иконка приложения.

# Версия 0.2.0

- Русские названия и описания всех 261 параметра, локализованные значения выбора и подсказки по режимам.
- Помощник настройки для чата и агентского программирования, чтение метаданных GGUF без загрузки весов.
- Обнаружение GPU через llama.cpp, выбор нескольких карт, резерв памяти и режим CPU.
- Проверка обучающего контекста, оценка KV для стандартных архитектур, сохранение настроек помощника в JSON.
- Просмотр изменений перед применением и запуск llama-fit-params из помощника.
- Статическая Windows x86-сборка без внешних Qt, OpenSSL и MinGW DLL; проверка релизов llama.cpp при запуске и вручную.

Проверки выполняются на синтетических GGUF и тестовых процессах. Настройки для реальной модели требуют проверки на целевом оборудовании.

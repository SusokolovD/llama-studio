# Версия 0.7.0

- Компактное окно мониторинга 360×520, режим «Поверх окон» и полные таблицы в отдельном окне «Подробно».
- Скорости префилла и генерации по промежуточным/итоговым строкам журнала llama.cpp, слот/задача, давность и время запроса.
- Время работы сервера с сохранением статистики при переоткрытии мониторинга и сбросом при перезапуске сервера.
- Проверки разбора логов, раздельных задач, фрагментированных строк, таймера и узкого интерфейса.

# Версия 0.6.1

- Исправлен разбор современного `llama-server --version`: semver, номер build и commit определяются отдельно; сравнение с релизами выполняется по build.
- Каждая проверка обновлений заново читает локальный exe; локальная версия сохраняется в результате при ошибке GitHub. В подсказке доступны путь и полный вывод, включая компилятор и архитектуру.
- Регрессионные проверки современного/старого формата, повторного чтения, ошибки сети и удаления локального бинарника.

# Версия 0.6.0

- Сценарий и CMake-пресет MSVC 2026 x64: статическая Qt, /MT, Release, тесты и проверка DLL-зависимостей.
- Отдельное окно каталога GGUF: фоновый рекурсивный поиск, фильтр, сортировка, метаданные, ошибки и выбор основной/черновой модели или проектора.
- Отдельное окно мониторинга: CPU, RAM, график, каждая NVIDIA GPU (температура, загрузка, VRAM, мощность, вентилятор); опциональные датчики Libre Hardware Monitor через WMI.
- Обход WOW64-перенаправления драйверных утилит в 32-битной сборке; тайм-ауты и остановка опроса при закрытии.

# Версия 0.5.1

- Раздел справочника о промптах для локальных моделей для кодинга: структура запроса, полезные формулировки, контекст проекта и шаблоны для реализации, отладки, ревью и IDE-агента.

# Версия 0.5.0

- Контекст fit принимает 0: автоподбор до максимума модели с учётом памяти; значение сохраняется в JSON.
- Вся площадь кнопок реагирует на нажатие, включая края.
- Подтверждение каждого выхода с безопасным ответом «Нет» по умолчанию.
- Windows Job Objects завершают сервер, fit и их потомков при аварии приложения.
- Тесты кликов по краям, отмены выхода, fit с нулевым контекстом и аварийного завершения дерева процессов.

# Версия 0.4.0

- Подробный справочник параметров в помощнике: температура, top-k/top-p/min-p, повторы, seed, резерв VRAM и настройка под задачу.
- Отдельная вкладка памяти: живой расчёт KV по GGUF, сравнение окон и форматов кэша, бюджет каждой GPU и ограничения оценки.
- Команды сборки вынесены в build-commands.json: программа и массив аргументов, импорт/экспорт, проверка JSON до выполнения, миграция прежних профилей.
- Возможность собрать статическую версию в отдельные каталоги, пока прежний exe открыт.

# Версия 0.3.0

- Вкладка обновления и сборки llama.cpp: исходники, редактируемые команды, папка бинарников и отдельная папка llama-build.

# Версия 0.2.0

- Русские названия и описания всех 261 параметра, локализованные значения выбора и подсказки по режимам.
- Помощник настройки для чата и агентского программирования, чтение метаданных GGUF без загрузки весов.
- Обнаружение GPU через llama.cpp, выбор нескольких карт, резерв памяти и режим CPU.
- Проверка обучающего контекста, оценка KV для стандартных архитектур, сохранение настроек помощника в JSON.
- Просмотр изменений перед применением и запуск llama-fit-params из помощника.
- Статическая Windows x86-сборка без внешних Qt, OpenSSL и MinGW DLL; проверка релизов llama.cpp при запуске и вручную.

Проверки выполняются на синтетических GGUF и тестовых процессах. Настройки для реальной модели требуют проверки на целевом оборудовании.

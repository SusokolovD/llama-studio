# Версия 0.10.0

- Рекурсивный каталог весов изображений с отдельным JSON-кэшем. Подбор SD 2.x / FLUX.3 / Qwen Image 2.1 и совместимых энкодеров/VAE по заголовкам, включая переименованные файлы в произвольных подпапках. Неоднозначные варианты требуют выбора.
- Встроенный auto-fit движка: резерв VRAM, автоматический режим, CPU или несколько GPU одного backend. Показаны размеры весов и свободная RAM; реальное размещение рассчитывается сервером при загрузке/генерации.
- Отдельный движок stable-diffusion.cpp: профили SD 2.1, FLUX.3 Image Klein, Qwen Image 2.1 и пользовательские копии, параметры запуска, процесс sd-server, журнал и открытие поставляемого сервером Web UI.
- Готовность через `/sdcpp/v1/models/status`, обработка занятого порта, ошибок запуска/завершения и незавершённых компонентов. Размеры сверяются с необязательным assets.json без повторного чтения весов и без скачивания.
- Переносимые начальные настройки: относительные пути, автоматический бюджет VRAM, отсутствие фиксированного номера GPU. Движок и все профили сохраняются в JSON; старые профили llama.cpp поддерживаются.
- Один движок за раз; остановка sd-server при закрытии, защита процесса Windows Job Object. Лимиты мощности из профиля и их сброс при выходе работают с обоими движками.
- Проверки команд, компонентов, API, жизненного цикла, выбора Web UI и восстановления профиля. Реальный SD 2.1 проверен на загрузку и остановку; FLUX/Qwen не запускались.

# Версия 0.9.3

- Во вкладке сборки можно указать произвольный репозиторий llama.cpp или форк и необязательную ветку. Git pull использует выбранный источник; пустой URL сохраняет прежнее обновление из upstream.
- URL, ветка и папка исходников сохраняются в JSON-профиле. Команды сборки и копирование бинарников выполняются как прежде; remotes локального клона не меняются.
- В README добавлены два скриншота интерфейса для просмотра на GitHub.
- Проверены обновление из форка, отличающегося от origin, выбор ветки/HEAD, остановка при ошибке pull и восстановление настроек профиля.

# Версия 0.9.2

- Исправлено закрытие без прав администратора: отказ записи с неизменившимся лимитом не требует сброса. Если сброс действительно не удался, доступны «Остаться» и «Выйти без сброса» с предупреждением о сохранении лимитов.
- В каталоге и выборе моделей работает фильтр типов «Все / Основная / Графика (mmproj) / Draft». Параметр запуска выбирается отдельно через «Использовать как».
- Автоопределение типа и ручное назначение через «Задать тип…». Назначения хранятся в JSON-кэше, переживают обновление метаданных и распространяются на части GGUF.
- Добавлены проверки отказа прав, обоих вариантов выхода, фильтрации и сохранения типов. Управление мощностью проверяется имитатором без изменения реальных GPU.

# Версия 0.9.1

- Лимиты GPU сохраняются по UUID в секции gpuPowerLimits текущего JSON-профиля и применяются перед запуском сервера.
- При обычном выходе изменённые карты возвращаются к заводским лимитам с проверкой результата; при ошибке приложение остаётся открытым.
- Сброс мощности не перезаписывает значения профиля; управление живёт в главном окне и работает после закрытия мониторинга.

# Версия 0.9.0

- Окно управления лимитом мощности NVIDIA из компактного мониторинга: выбор GPU по UUID, диапазон драйвера, ручные ватты, процентные заготовки и возврат заводского лимита.
- Проверка диапазона перед записью и чтение лимита после применения; обработка неподдерживаемых карт, отказа в доступе и неподтверждённых изменений.
- Офлайн-справка о балансе температуры, префилла, генерации и энергопотребления, с примерами расчётов и настройкой нескольких GPU.

# Версия 0.8.0

- Общий JSON-кэш метаданных GGUF для каталога и помощника. Каталог открывается из сохранённого снимка без сканирования; обновление проверяет размер/время файлов, доступно принудительное перечитывание.
- Атомарная запись кэша с блокировкой и объединением изменений, восстановление после повреждения JSON.
- Прямой режим `LLAMA_STUDIO_STATIC_MSVC` в CMake, включённый по умолчанию для MSVC: static Qt, /MT и /MTd, статические внутренние библиотеки. Исправлен выбор /MDd для динамической конфигурации Debug.
- Восстановление последнего успешно открытого/сохранённого профиля при запуске; отсутствующий или повреждённый профиль не мешает открытию приложения.
- Выбор основной модели, проектора и draft-модели из JSON-списка: фильтр «Все» или конкретный каталог, поиск и возможность открыть произвольный файл с любым расширением. Тот же выбор доступен в помощнике.
